# Pedidos Cusco

Sistema web para gestionar pedidos de comida local, desarrollado para una startup en Cusco.

## Descripción
Permite a los clientes consultar el menú de restaurantes locales, realizar pedidos
y a los restaurantes gestionarlos.

## Tecnologías previstas
- Frontend: HTML, CSS, JavaScript
- Backend: por definir
- Control de versiones: Git y GitHub
