# Pedidos Cusco

Sistema web para gestionar pedidos de comida local, desarrollado para una startup en Cusco.

## Descripción
Permite a los clientes consultar el menú de restaurantes locales, realizar pedidos
y a los restaurantes gestionarlos.

## Tecnologías previstas
- Frontend: HTML, CSS, JavaScript
- Backend: por definir
- Control de versiones: Git y GitHub

## Cómo contribuir

1. Clona el repositorio:
```bash
   git clone https://github.com/Gitomaki9/pedidos-cusco.git
   cd pedidos-cusco
```
2. Actualiza `main` antes de empezar:
```bash
   git checkout main
   git pull
```
3. Crea una rama para tu tarea:
```bash
   git checkout -b feature/nombre-de-la-tarea
```
4. Haz tus cambios y regístralos:
```bash
   git add .
   git commit -m "Describe el cambio"
   git push -u origin feature/nombre-de-la-tarea
```
5. En GitHub, abre un Pull Request hacia `main` y pide que un compañero lo revise antes del merge.

### Reglas del equipo
- No se hace push directo a `main`.
- Un commit por cambio lógico, con mensaje claro.
- Cada tarea va en su propia rama.
